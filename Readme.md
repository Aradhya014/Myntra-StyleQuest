# 👗 Style Quest – AI-Powered Gamification for Myntra



> **Transforming shopping into an engaging, personalized, and interactive experience.**



Style Quest is an AI-powered gamification feature designed for Myntra to increase user engagement and retention. Instead of limiting users to browsing and purchasing, Style Quest introduces daily missions, AI-powered personalization, streaks, rewards, and fashion challenges that encourage users to return every day.



---



## 📌 Problem Statement



Gen Z and Gen Alpha don't just shop for fashion—they use it to express their identity.



While Myntra already provides an excellent shopping experience with personalized recommendations and seamless product discovery, there is an opportunity to further enhance user engagement beyond purchasing.



Style Quest addresses this by making shopping interactive through AI-powered missions, personalized recommendations, streaks, and rewards.



---



## 💡 Solution



Style Quest adds a gamification layer on top of Myntra's existing shopping experience.



Users complete personalized fashion missions, earn Sparks, maintain daily streaks, unlock achievement badges, and redeem exciting rewards while exploring fashion in a fun and engaging way.

## 🚀 Installation



Clone the repository



```bash

git clone https://github.com/Aradhya014/Myntra-StyleQuest.git

```



Navigate to the project



```bash

cd Myntra-StyleQuest

```



Install dependencies



```bash

npm install

```



Create a `.env` file



```env

GEMINI_API_KEY=YOUR_API_KEY

```



Start the project



```bash

npm run dev

```
